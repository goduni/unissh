# UniSSH screenshots

The v0.7.0 gallery shows the current client and the fully redesigned administration panel in
light and dark mode. All hosts, accounts, file listings, counters, and terminal output are synthetic
demo data. Domains use the reserved `example.net` namespace.

The images are rendered from the product's React interfaces with fixture-backed native/API calls.
macOS window controls, rounded window edges, a backdrop, and the admin panel's browser frame are
added for presentation. These are browser-rendered screenshots, not native macOS runtime tests.
Each PNG is 3136 × 2056 pixels (2× scale).
