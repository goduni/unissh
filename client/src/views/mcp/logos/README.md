# Agent logos

Monochrome Claude, Codex, OpenCode and Cursor marks from
[Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons),
retrieved on 2026-09-22. The bundled files are unchanged and covered by the
adjacent MIT license. Brand names and marks belong to their respective owners.
These marks identify compatible clients; they do not imply endorsement.

The UI uses local SVG masks so marks follow the theme without network requests.
